# Getting help

| I want to… | Go to |
| --- | --- |
| Ask how to size something | [Discussions → Q&A](https://github.com/torrentalle/memorylimit-dev/discussions/categories/q-a) |
| Report wrong output or a parsing problem | [New bug report](https://github.com/torrentalle/memorylimit-dev/issues/new?template=bug.yml) |
| Ask for a new platform or format | [New platform request](https://github.com/torrentalle/memorylimit-dev/issues/new?template=platform-request.yml) |
| Suggest an idea | [Discussions → Ideas](https://github.com/torrentalle/memorylimit-dev/discussions/categories/ideas) |
| Report a security problem | [Private advisory](https://github.com/torrentalle/memorylimit-dev/security/advisories/new) |

Issues and discussions are public. Remove hostnames, tokens and anything sensitive from pasted samples.
