VMware vSphere Memory Sizing Calculator

vSphere gives each VM three memory controls. The reservation is memory the host guarantees and never takes back; the limit is a ceiling the VM can't use more than; shares only decide who wins when VMs compete for the same host's memory. Unlike a container runtime, hitting the limit doesn't kill anything — the hypervisor starts ballooning and swapping the VM, so it slows down gradually instead of failing fast. This calculator sizes the reservation and limit from real usage.

Where do I get these numbers?

Measure from inside the guest: vSphere's own "active" memory underestimates what the OS needs, and "consumed" never shrinks. With node_exporter, run a range query over a representative period (a week is a good default):

node_memory_MemTotal_bytes{instance="vm1:9100"}
  - node_memory_MemAvailable_bytes{instance="vm1:9100"}
