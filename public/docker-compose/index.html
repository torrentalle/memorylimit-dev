Docker Compose Memory Limits Calculator

Docker Compose's deploy.resources block controls how much memory a service reserves and how much it's allowed to use before it gets killed. This calculator sizes both values — plus the legacy mem_limit equivalent for Compose setups without Swarm — from your service's observed average and peak memory usage.

Which query should I paste?

Use a range query over a representative period (a week is a good default) for one service. Every sample is averaged, and the highest becomes the peak — an instant query only gives one value per container.
