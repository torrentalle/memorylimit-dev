Support

MemoryLimit is an open-source project and support happens in the open on GitHub. Pick the place that matches what you need. A free GitHub account is required to post.

  • How do I size something? Ask in Discussions → Q&A.
  • The output looks wrong or my data was not parsed. Report a bug. Remove anything sensitive from the sample first: the site never sees your data, but a public issue does.
  • I need another platform or format. Request a platform.
  • I have an idea. Share it in Discussions → Ideas, or open a feature request if it is concrete.
  • I found a security problem. Please report it privately, not in a public issue.

Support the project

MemoryLimit is free and has no accounts or paywall, and that does not change. If it saves you time, you can sponsor its upkeep through GitHub Sponsors, monthly or as a one-time gift. Sponsorship helps cover hosting and the time spent keeping the sizing rules correct across platforms and answering questions and bug reports. Every sponsor gets the same tool as everyone else.

Not in a position to sponsor? A star on GitHub, a bug report or telling a colleague helps just as much.
